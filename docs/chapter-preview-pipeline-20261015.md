# 章节预览与定位管线更新（2026-10-15）

## 本轮实现

### 多章节预览

代码检查发现，缩略图气泡继承了轨道只有 16/20 pt 的高度约束，同时用固定负偏移定位。有章节时多出标题行，布局未考虑内容高度。本轮让气泡保留固有高度，以自身底边对齐轨道上方，并继续按整条时间轴计算水平位置；章节不再改变图片可用高度。异步缩略图完成后直接发布图片，缓存轮询仍负责接收已取消悬停请求留下的有效结果。主窗口与迷你窗口共用此实现。

另一条可能导致无图的路径是 AVFoundation 无法读取 mpv 可以播放的容器。新增可选 FFmpeg SDR 缩略图回退：

- 默认仍使用 AVAssetImageGenerator；一次 FFmpeg 成功后，当前文件后续预览直接走该路径，避免重复等待 AVFoundation 失败。
- 只读取本地文件，只在源色彩元数据确认 SDR 时启用；HDR、杜比视界及未知色彩不走该回退，以免生成错误颜色的缩略图。AVFoundation 如能读取这些文件，仍可提供预览；否则明确提示不可用。
- 使用已安装的 `/opt/homebrew/bin/ffmpeg`、`/usr/local/bin/ffmpeg`，或未来应用内的辅助程序。本轮没有下载或打包 FFmpeg 可执行文件。开发机版本为 8.1.1。
- `Process` 传递独立参数，无 shell。协议白名单只有 file/pipe，PNG 单帧通过内存管道传递，不写中间图片，也不改变播放器解码设置。
- 每窗口一个预览任务；单线程 FFmpeg 解码/缩放，最长 4 秒，图像数据上限 2 MiB，诊断保留末尾 128 KiB，缓存最多 96 张。后台 FFmpeg 预热间隔至少 10 秒，悬停优先。
- `-copyts -start_at_zero` 保留文件相对时间轴，使用 `showinfo` 解码时间显示缩略图时间，不把鼠标目标当成已解码时间。多章节文件头可能很长，所以保留诊断尾部以免丢掉帧时间。
- 换文件/关闭会取消旧任务；失败探测短暂退避，不能解码时显示说明。缩略图不是播放器 ICC/滤镜效果的像素级复刻。

这是基于源码的修复，尚未在用户的多章节样片上验证。可能的容器兼容问题与布局问题分开处理，没有宣称所有 HDR/MKV 预览已获支持。

### 自适应操作与导航

播放条宽度不足 680 pt 时收起倍速、信息、迷你模式和音量滑条，相关操作仍可从播放菜单进入（音量菜单提供常用档位，键盘音量快捷键仍可用）。保留播放、快退/进、静音、队列、增强设置与全屏。仅保留一组气泡锚点，避免自适应候选视图同时绑定同一弹窗。

新增统一的 Chapters & Markers 菜单：章节、时间标记及新增标记都可访问。播放菜单与主窗口/迷你窗口时间轴右键菜单共用此入口。保留减少动态效果偏好，未恢复流光。

### 连续定位与过时推理

- 新的绝对定位请求使仍在客户端队列中等待的旧绝对定位失效；切文件/停止也会撤销过时请求。已发送给 mpv 的命令仍按 mpv 时序完成。
- 相对定位和逐帧保留队列顺序，避免把“定位后再前进”变成从旧位置前进。
- 继续使用请求 ID 匹配和临时目标保持，防止旧时钟使进度条回弹。定位后优先请求目标缩略图。
- RIFE、Apple SR/FI、FSRCNNX 在昂贵初始化、输入转换、模型调用和输出处理之间检查 generation。若期间发生跳转/销毁，释放当前输入，跳过剩余工作，现有 worker 负责丢弃旧输出并重置历史。
- 已提交的 GPU 工作无法由这些检查中止；没有宣称实现 GPU kernel 抢占。每滤镜一个工作任务及有界输出队列保持不变。
- 新增 `iive-seek-queue-ms`、`iive-seek-command-ms`、`iive-seek-coalesced` 到原有 `--metrics` 快照；前两项只测客户端排队和命令返回，**不代表** demux、解码、推理完成或画面呈现延迟。

## Metal/EDR 路线判断

本地固定版 `.research/mpv-native/include/mpv/render.h` 只列出 OpenGL 与 software API，未提供 Metal render API。`native/Player/VideoView.m` 使用 OpenGL context 与 `render_gl.h`。当前构建明确禁用 Vulkan，不能通过新增 SwiftUI 开关得到 Metal/EDR 输出。

下一阶段应先增加 demux/解码/推理/实际呈现的同一请求追踪，确认瓶颈，再尝试输出后端。可研究独立的 GPU-next/libplacebo 原生宿主，或自定义帧/IOSurface → Metal 显示桥接，但后者需补齐字幕、PTS/音画同步、色彩转换、缩放及截图功能，不能直接替换当前稳定路径。当前 Dolby Vision 功能仍是实验性 RPU → SDR 映射，没有新增 HDR/EDR 或 FEL 支持。
