## 实现

- 新增 `TierPreparation`，在独立串行准备队列创建新档位模型，并执行一次真实推理及所选输出格式转换。原来仅用空时间步播种，不能预热完整 IFNet。
- 准备期间播放 worker 不等待模型完成，也不继续运行旧模型推理；在原有时间轴输出源画面保持帧，全部标记 `synthesized=false`。这是临时源画面过渡，不是 AI 插帧，界面显示 `Switching model · source playback`。
- 每个源帧到达时非阻塞轮询准备结果。完成后用最新源帧播种新流，再恢复 AI 推理；不 seek、不清空已有输出队列。背景准备结束后才交接新流，禁止两线程同时使用同一流。
- 每个处理器最多持有一个待交接任务，进程内准备任务串行执行。超时 30 秒则报错并恢复源播放；改变档位、定位、EOF、销毁会取消旧任务。已提交的 GPU 操作无法强制中断，完成后丢弃过期结果；队列中的取消任务释放持有的源帧。
- 过渡保持帧不进入稳态推理延迟窗口。`tier_switch_ms` 现在记录从请求至交接的总准备时间，包含后台预热和轮询间隔，不等于播放阻塞时间。
- 保留同步 C ABI，新增 `iive_stream_request_tier`（0 已应用、1 准备中、-1 失败），mpv 适配器使用新接口。

新旧模型在准备时仍会暂时共存，未增加永久第二模型缓存。后台 GPU 预热仍可能影响渲染调度，且交接时播种最新源帧仍有小量同步工作，不能宣称无缝切换。
