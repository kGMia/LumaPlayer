# Inline system HDR playback

AVKit now renders inside the main Luma window and Mini Player. Existing transport routes pause, seek, volume, mute, rate and frame stepping to the active backend. Local HDR MP4/MOV/M4V automatically attempt AVKit once per media epoch; Picture & Color offers a manual switch and return. Failure or startup timeout restores mpv at the native position with the intended pause state. mpv retains the queue. Native end-of-item advances the queue or honors file/queue repeat.

HDR eligibility is not proof of a specific Dolby Vision profile or measured HDR output. Color management belongs to AVKit. MKV and authenticated network media retain mpv tone mapping. Enhancements and live/second subtitles are not available on this path; settings are preserved. Audio/subtitle menus now use AVKit media-selection groups asynchronously loaded for the current item. Selection and subtitle Off stay in AVKit. Unsupported external/live/second subtitles show an explicit limitation. Native IDs are never sent to mpv or written over its per-file track preferences. Frame capture and Live Text use AVAssetImageGenerator at the requested playhead, exporting SDR PNG without subtitles or HDR metadata. Only one capture runs per player; replacing media cancels generation. Picture filters and ICC overrides are mpv-only. Output-FPS/drop telemetry from mpv does not describe AVKit.

Basic signed build/package verification only; actual color, fullscreen/Mini transitions, queue completion and seek interaction require user testing. Next: HDR-preserving image export and native output telemetry where supported.

Language defaults use AVPlayerMediaSelectionCriteria (ordered BCP-47/ISO 639-2/T languages); empty lists preserve system defaults. Automatic-subtitles Off deselects the native legible group when allowed. Preferences apply to new sessions, not manual selections in the current session. Enhancement, decoder, picture and audio-device panels expose a shared native-backend notice; mpv-only controls are disabled and a return action remains accessible.

Native track memory stores AVKit option property lists (including explicit Off), separately from mpv IDs; bounded to 100 files and invalidated by size/mtime. Explicit selections override default languages on reopening when media-selection memory is enabled. Clearing playback memory clears both stores.

Cross-backend handoff now matches embedded tracks by language/title only when unique, including explicit Off. Native remembered selections override the incoming mpv choice. Ambiguity on return keeps mpv selections and displays a notice; track indices are never treated as shared IDs. Script/region subtags are not collapsed.

HDR export assessment (installed SDK): AVAssetImageGenerator exposes `.matchSource`; ImageIO exposes `kCGImageDestinationEncodeRequest` with ISO HDR / ISO gain-map requests. Next implementation should use a separate HEIF export action, verify destination support and resulting dynamic-range metadata by reopening the encoded file, and reject silent SDR output. Dolby Vision video metadata cannot be assumed to survive conversion to a still. PNG export remains explicitly SDR; a separate experimental HEIC path is described below.

Live Text now pauses and displays the captured frame inline in the main/Mini window, using ImageAnalysisOverlayView for direct text selection/data detectors. Transcript remains available in a popover. mpv uses screenshot-to-file video (no subtitle/OSD overlays); AVKit uses source-frame decoding. Burned-in captions remain image pixels and cannot be excluded. Done leaves playback paused; play/seek/file navigation dismisses the capture.

Experimental HDR image export is now a separate contextual action for AVKit: source-range image generation → ISO HDR HEIC encoding → ImageIO HDR decode/readback. Source and decoded headroom must exceed 1; otherwise export fails before writing the requested destination. PNG defaults remain SDR. This is a high-quality lossy still export, not lossless Dolby Vision preservation; flat/dark frames with unmeasurable headroom may be rejected. Compile verification only; codec/color behavior awaits user testing.
