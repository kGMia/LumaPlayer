# 2026-10-14 队列与窗口切换更新

本记录取代上一轮「迷你模式保留原窗口可见」的行为。最新开发应用为 `build/PersonalTeam/IIVE Player.app`。

## 迷你窗口

- 进入后隐藏主窗口（orderOut），保留其实例、队列、设置和播放会话；退出后显示原窗口。
- 使用 180 ms 窗口透明度淡入淡出。开启系统 Reduce Motion 时直接切换。不对视频尺寸做逐帧缩放动画，避免反复触发超分资源重配。
- 从全屏进入迷你模式时先退出全屏，避免留下空的全屏 Space。恢复后为普通窗口；可再次点击全屏。
- 关闭迷你面板、Esc、双击视频恢复主窗口；重新唤出主窗口也会恢复视频。切换期间防止重复操作。

## 同目录自动队列

Settings → General → Add Media from the Same Folder 保留持久化开关，队列菜单也提供同一开关和 Scan Current Folder。

修复开启开关时不扫描当前文件的行为。打开单文件时同样会扫描。后台读取当前目录，识别本地音视频扩展名；不递归，不加入隐藏文件或符号链接。扫描错误和新增数量显示在队列及设置中。

追加前在 mpv 客户端串行队列中核对当前条目，再按规范化文件路径去重。保留已加入的手动条目，不重新加载当前媒体。播放文件已变化时放弃旧扫描；取消任务清除扫描状态。目录读取成功不代表每个容器的所有流都能解码。

## 队列排序与显示

队列标题右侧菜单和 Settings → General → Play Queue 均可设置，偏好持久化。

- **Custom / Added Order**：按加入顺序；可在列表拖动重排。切换到其他排序再切回，会恢复本次播放会话保存的自定义顺序。
- **Filename**：自然文件名升序（例如 2 在 10 之前）。
- **Date Created**：文件创建时间从早到晚，无法读取的时间排在最后；相同时按条目 ID 稳定排序。
- **Title & Duration**：标题、时长。
- **Cover, Title, Duration & Size**：增加视频预览缩略图、文件大小。

排序同步修改 mpv 播放列表，所以下一个/上一个与可见顺序一致。操作使用稳定条目 ID，并在执行时验证实际队列，避免排序期间使用旧行号播放或删除错误文件。只有自定义模式允许拖动。

时长和缩略图通过公开 AVFoundation API 在后台串行加载并缓存（最多 128 个结果），不新建 mpv 播放实例。缩略图是视频预览帧，不保证是媒体嵌入的海报。系统无法读取的容器、音频无封面等情况显示占位图或 N/A；当前条目可使用实际 mpv 时长。AVFoundation 元数据支持范围可能小于播放器的 FFmpeg 解码范围。未增加 FFmpeg 子进程探测，以免队列浏览占用增强播放的处理资源。

## 全屏响应

点击全屏后异步等待当前 GL 绘制结束，再调用系统全屏切换；同一转换期间忽略重复请求。系统绿色按钮也进入相同的转换状态管理。全屏动画期间延后 OpenGL drawable 的重复更新和增强滤镜规划，在最终尺寸恢复；系统没有发出结束通知时提供 4 秒恢复保护。

没有改变 mpv 的默认音画定时参数。转换期间视频绘制可能短暂保持上一帧；最终目标尺寸需要新的增强资源时，模型准备仍可能有延迟。这是针对主线程等待及中间尺寸反复重配的修复，**没有实测证明所有片源下的全屏卡顿均已消除**。
