## 修复与优化

1. **统一事件时钟**：上一版慢帧使用 `CLOCK_MONOTONIC`，快照使用 `NSProcessInfo.systemUptime`，两者不能直接相减。本次事件时间戳改为与快照相同的时钟，并输出 `slow_event_clock=system-uptime`。各段耗时仍使用原有单调时钟，不受时区或系统日期影响。
2. **兼容旧日志**：没有时钟标识的慢事件不再生成错误的相对时间，`elapsed_s` 留空，另给出实际收到该事件的快照时间 `observed_at_s`。不会用推测的常量偏移伪造事件时间；这些记录不能用于精确对齐睡眠前后的事件。
3. **统计处理移出渲染锁**：锁内仅复制有界的 C 数据和更新消费游标；窗口排序、百分位计算、字典与数组分配均在锁外进行，减少性能 HUD/日志采集与渲染线程的相互等待。该等待此前未直接测量，本轮不宣称具体性能收益。
4. **后台缩略图让步**：定位、拖动进度、窗口过渡、模型预热或换档期间，不启动新的推测性预览解码；正在播放且 RIFE P95 达到帧对预算的 80% 时，也暂缓预加载。条件恢复后继续。暂停时不因旧推理 P95 阻止预加载；直接悬停请求不受此限制。已经启动的解码仍由原有取消/超时机制管理。

未改变 RIFE 模型、自动降档策略、显示同步或 HDR/EDR 路径。
