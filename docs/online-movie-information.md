# Online movie information

Settings → General → Online Movie Information. Disabled by default. Save a TMDB **API Read Access Token** in Keychain, enable the feature, then open Information → Find Movie or TV Information. Edit the proposed filename-derived title/year if needed. Search checks up to six candidates, retrieves their runtime/details, and sorts by absolute runtime difference in minutes. Duration stays local. Missing runtime sorts last; ties retain provider search order. Confirm a candidate to save; no automatic attribution from filename alone.

Local movies and TV episodes, English/Simplified Chinese/Traditional Chinese (Taiwan). Explicit S02E03 / 1x04 filenames prefill season and episode; both remain editable (season 0 for specials). TV year filters the series premiere. Up to six series candidates are checked for the requested episode, ranked by the actual episode runtime; missing episodes (404) are skipped. Multi-episode files and absolute numbering are not inferred. Poster URLs returned by movie/episode searches automatically enter a background download queue, including batches; results do not wait for the image. Confirmed matches also refill the cache when accessed. No remote-URL lookup or automatic NFO write. NFO and embedded tags win; online fields fill blanks. No numeric match-confidence claim: alternate cuts, credits and frame-rate conversions can change runtime.

Confirmed records are bounded to 100, keyed by path hash, invalidated by file size/mtime, and stored in app preferences. Disable hides them and stops active searches; Remove Match/Clear Online Matches removes them. Search is explicit, never on playback startup. Requests use HTTPS with Bearer auth, disabled redirects/cookies, bounded detail count, request timeouts and visible auth/rate-limit errors. No raw error-response body or token is logged.

TV API: https://developer.themoviedb.org/reference/search-tv ; https://developer.themoviedb.org/reference/tv-episode-details

Official docs: https://developer.themoviedb.org/docs/authentication-application ; https://developer.themoviedb.org/reference/search-movie ; https://developer.themoviedb.org/reference/movie-details ; https://developer.themoviedb.org/docs/faq

Validation: build plus offline filename/ranking/precedence checks. Authenticated API and GUI matching require a user-supplied Token; not yet verified here.

Batch episodes: after confirming one episode, choose Batch Match Episodes. Same-title local siblings are gathered from the current folder/queue, with optional file multi-selection; explicit season/episode numbering is required. One confirmed series ID is reused, series details and credential are read once, and episode requests run sequentially with cancellation. Each batch holds up to 50 files; existing matches start unchecked and unmatched files take priority in the next batch. Review results before applying; changed files are skipped and preferences persist once. Missing episodes continue; auth/network/rate-limit errors stop the batch while preserving completed results. No background playback lookup or media/NFO writes.

Poster cache: 32 MiB decoded memory, 128 MiB / 256 files on disk under ~/Library/Caches/com.august.lumaplayer/OnlinePosters. Shared requests, bounded image decoding, official TMDB HTTPS URLs only, no token or cookies, no redirects. Clear Poster Cache in settings cancels pending work and removes cached files; disabling online information cancels downloads. Local artwork still takes display priority.
