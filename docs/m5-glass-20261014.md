# M5 pipeline and Liquid Glass player update — 2026-10-14

This update is for the separate **IIVE Player**, targeting macOS 27 / Xcode 27, arm64. It does not modify IINA.app. Validation is deliberately limited to a build, a short native pipeline check and a short GUI check, as requested.

## Pipeline changes

- Native interpolation → native SR now passes compatible NV12 IOSurface-backed `CVPixelBuffer`s directly. Both RIFE and Apple outputs use the shared adapter in `native/mpv-filter/iive_surface.c`; FSRCNNX / Apple input first attempts acquisition before falling back to swscale.
- Acquisition requires an owned read-only AVBuffer identity, unchanged plane pointers/strides/dimensions, NV12 video range, centered chroma and BT.709 / BT.1886. A mutex protects the small live-surface registry; references are retained before returning and entries disappear when the last mpv buffer reference is freed. There is no lookup by guessed private AVBuffer opaque layout and no cache retaining old frames.
- `input_surface`, `shared_inputs` and `copied_inputs` report the path actually taken. These counters are cumulative for that filter instance, including processing around seeks; they are not presentation counts.
- This removes an intermediate NV12 conversion/copy. Decoder conversion, OpenGL upload and some other paths still copy; this is **not an end-to-end zero-copy player**. Inference queue/pool limits and generation cancellation remain in place.
- Cache VideoToolbox capability queries per source geometry. Query expensive `vo-passes` only while a GLSL shader needs execution verification.
- Models continue to use the existing FP16 MPSGraph executables and fused Metal NV12 input/output kernels, with release-optimized native libraries even under a Debug app.

M5 GPU Neural Accelerators are distinct from the Apple Neural Engine (ANE). We have not measured accelerator occupancy or proved individual operators run on those units. The UI now reports utilization as N/A instead of claiming it is active. This change improves data movement; it makes no unmeasured percentage-speedup claim and does not replace or quantize the trained models.

## Player changes

- System `glassEffect` and `GlassEffectContainer` for a floating playback strip and optional video-information overlay. A dark scrim keeps labels readable over bright video; reduced transparency uses an opaque native background, and reduced motion disables control fade animation.
- The timeline, transport, speed, volume, information toggle, quick settings and full-screen controls float over the video. They hide after three seconds of inactivity while playing; pause, scrubbing, pointer interaction and an open settings popover keep them visible.
- Quick settings expose master enable, SR, FI, RIFE tier, target FPS and fallback. The full inspector remains available for audio, subtitles and diagnostics.
- Native full screen: **⌃⌘F**, toolbar/transport button, or double-click video; **Esc** exits. Entering full screen closes the inspector and hides the window toolbar. Leaving restores the previous inspector state. Full-screen settings remain accessible from the floating strip and **⌥⌘I**.
- **⌘I** toggles the persistent information overlay. **Space** plays/pauses, including restarting from EOF; **← / →** seek five seconds.

Information comes from the live mpv session, sampled about four times per second:

| Label | Meaning |
| --- | --- |
| Source | Decoded source width/height, codec, pixel format and color description |
| Source FPS | Container-reported cadence; can be inaccurate for VFR or bad metadata |
| Filter output / Output | Dimensions after native filters, before display shaders |
| Output FPS (estimated) | mpv `estimated-vf-fps`: recent frame timestamps, not screen presentation, not multiplied by playback speed |
| Picture area | `osd-dimensions` less video margins, including final display scaling |
| Render viewport | Retina backing-pixel dimensions of the render surface |
| Render callbacks | Renderer callbacks per second, including redraws |
| Measured display FPS | N/A: physical presentation is not measured |
| FI / SR job times | Latest per-stage job time including conversion and inference; not end-to-end latency |

Paused / EOF cadence remains the last timestamp estimate. Seeking and tail frame durations can move the estimate away from the nominal target. The expanded inspector explains the distinction, rather than synthesizing a target frame rate as telemetry.

## Basic results on this base M5

- `scripts/build-player-modern.sh`: Debug arm64 / macOS 27 build succeeded. New Swift files and shared C adapter are visible in the checked-in Xcode project; existing Xcode project customizations were preserved.
- `python3 scripts/smoke-native-models.py`: passed. At the sampled point RIFE fast/48 generated 5 frames, SR emitted 9 frames, **9 shared inputs / 0 copied inputs**, and output was **2560×1440 NV12, BT.709 limited range, centered chroma**. Both stages active; exit 0. See `../benchmarks/results/native-models-20261014-114514.json`.
- Short GUI playback used the repository's 12-second 720p24 synthetic fixture, RIFE fast/48 + FSRCNNX Metal Fast. Observed active stages, **48.000 estimated output fps**, 1440p native output and shared SR input. The first GUI run recorded one dropped frame (including startup), so it is not claimed to be drop-free. Observed floating controls, native full-screen entry/exit and settings popover. This is not a sustained throughput/quality benchmark or a representative movie test.
- Final visual-only changes (dark scrim and full-screen safe-area extension) compiled successfully but were not visually rechecked: macOS locked before the final screenshot. Summary: `../benchmarks/results/m5-glass-basic-20261014.json`.
- Raw GUI snapshots: `../benchmarks/results/glass-ui-20261014.jsonl` and `glass-ui-final-20261014.jsonl`. The 250ms samples are not an exhaustive per-frame inference latency distribution.

Build/run:

```sh
scripts/build-player-modern.sh
open 'build/Xcode/Build/Products/Debug/IIVE Player.app'
```

Alternatively open `IIVEPlayer.xcodeproj`, choose **IIVE Player → My Mac**, and Run in Xcode 27. The app still depends on this workspace and local Homebrew libraries; it is not yet a portable distribution.

## Next measurable optimization

Use an Instruments Metal System Trace on fixed 720p/1080p clips to separate decode/conversion, MPSGraph, SR, OpenGL upload and presentation costs before changing model precision or replacing kernels. A Metal presentation path and VideoToolbox decode-surface import could remove remaining copies but need color, seek and lifetime validation. Avoid making balanced/HQ the default based on short fast-model tests. Keep RIFE fast/48 as the first route to evaluate.
